# Terminals

Terminals run on the machine hosting the connected environment. Switching threads or hiding a
terminal leaves its shell and commands running. When a connection returns, the client reattaches
to the existing terminal if the server is still running.

Use **Close Terminal** to end a terminal session, or type `exit` to leave its shell. Restarting or
updating the T3 Code server stops its terminal processes, so let active commands finish first.
